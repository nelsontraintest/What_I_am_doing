FOR ME (IC)

How to Record Work (daily habit)

Keep the boss-facing board clean. Record projects as cards. Record daily small asks as mini-tasks under those cards.

Golden rule Board card = something a boss cares about as an outcome.
Mini-task = a small step today inside that outcome. Do not create a new board card for every tiny request.
✓ Do One card: “Fix checkout payment timeout”
Mini-tasks under it: “Check webhook logs”, “Patch retry”, “Ask Boss B to smoke-test”
✗ Don’t Four separate board cards for those same four tiny steps — the board becomes noise and bosses stop reading it.

Daily workflow

  1. Open the live board → click ✏️ Manage / Record Work.
  2. First time only: click ⚙️ Boss Names & Status → set real boss names and your bandwidth status.
  3. When a boss asks for a new project / outcome → fill the form → choose stage → + Add Task.
  4. When they ask for a small thing inside an existing project → find that card → type in Add a mini-task for today… → Enter.
  5. Tick mini-tasks as you finish. Move the parent card between Doing / Up Next / Blocked / Done with the stage dropdown.
  6. Reorder a stage by dragging the grip on a card, or with ↑ / ↓ while editing. Drop a card on another stage to move it. The Future vault stays in target-date order.
  7. Publish so bosses see the update (see “How to publish updates” below).

Click a card to expand a long mini-task list. Double-click a card to edit it. Ctrl+Z undoes the last board change (50 steps). Ctrl+Shift+Z redoes. On a Mac, ⌘Z and ⌘Shift+Z do the same. Typing in a text field keeps the normal text undo.

Which stage should I use?

🔥 Doing
Hands-on now. Keep to 1–2 cards so you finish, not thrash.
📋 Up Next
Queued and ordered. Default for new asks that are not urgent start-today.
🚧 Blocked
Waiting on someone else. Write the blocker in the note (who / what).
🕰️ Future Vault
Months or years later. Add Target Date (+6m / +1yr / +2yr), reminder plan, and runbook steps. Then download .ics or Send to Outlook.
✅ Done
Finished. Leaves a short proof trail for bosses.

Long-term tasks (the “2 years later” question)

  1. Stage = Future / Long-Term
  2. Set Target Date (use +2yr if needed)
  3. Write How to Do It (Runbook) so future-you still knows the steps
  4. Click Download Calendar Alarm (.ics) or Send to Outlook

When the due date is within 30 days, the board shows a yellow wake-up banner and a button to move it into Up Next.

What Goes Where? (cheat sheet)

Use this when you are unsure whether to create a card or a mini-task.

New board card
“Build the Q4 usage export”, “Fix production checkout timeout”, “Renew SSL in 2028”
Mini-task under card
“Pull CSV”, “Remove duplicates”, “Send draft to Boss A”, “Ask IT for DB access”
Blocked note
“Waiting on Boss C for vendor contact”, “Need read-only DB credentials from IT”
Future Vault
Anything due after the current sprint/quarter that must not be forgotten

How to Publish Updates So Bosses See Them

Edits first save in your browser. Pick one method below so bosses see the same board on their computers.

  1. 🚀 Publish to GitHub (best daily habit) — needs a Fine-grained Personal Access Token with Contents: Read & Write for this repo. Click once after you update.
  2. 📥 Download data.json — replace the file in the repo and commit if you prefer Git manually.
  3. 🔗 Copy Snapshot Link — paste into Slack / Teams / email when you need a quick share without committing.
After GitHub publish, wait about 30–60 seconds, then refresh the GitHub Pages URL. That is what bosses should bookmark.
